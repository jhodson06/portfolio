# Joshua Hodson Engineering Portfolio

Static portfolio site for Joshua Hodson.

## Files

- `index.html` contains the page content and project links.
- `hexapod-project.html`, `playing-card-project.html`, `local-ai-workspace.html`, `vex-robotics.html`, and `additional-projects.html` contain the project detail pages.
- `styles.css` contains the responsive layout and visual system.
- `script.js` contains the mobile navigation behavior and icon setup.

Open `index.html` in a browser to preview the site. The project illustrations live in `assets/` and can be replaced with final photos using the same filenames.
